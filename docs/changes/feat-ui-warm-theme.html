Warm "CRM Pro UI" theme — frontend rebuilt 1:1 to match the prototype

design handoff · branch feat/ui-warm-theme · source: reference/CRM-PRO.dc.html + screenshots/*.png

What changed

  • The entire frontend was brought 1:1 to the designer's warm "CRM Pro UI" prototype — not just a recolor, but a rebuild of every screen's structure to match the reference, while keeping the real data (CRM/ERP), logic, RBAC, and drag-and-drop.
  • Palette: brick red #BF322B + ochre #E3B32B on a cream background, frosted-glass cards, a dark floating sidebar, Arial. Styles are inline + hand-written SVG, matching the reference.
  • Shell: a collapsible sidebar with a "floating disc" indicator (3 layers on transform + icon cross-fade), a glass topbar (search/bell/avatar chip), the active menu item in dark #2b303c.
  • Animations: a screen-entry scrIn effect when navigating between sections, a tab-switch animation, a slide-in deal drawer, a smooth sidebar morph, thin themed scrollbars.

Repro steps (golden path)

  1. npm run dev → http://localhost:3000 (log in as head of sales).
  2. Menu: click the hamburger — the sidebar expands smoothly, the active item's disc indicator is fully visible and slides on navigation.
  3. Deals: saved-view pills (All/Mine/🔥Urgent/No next step); open a card → the drawer slides in from the right (a pill-based stage tracker, an "AI extracted → confirmed" feed); drag a card between stages — drag-drop works; stage-change buttons are visible (#256).
  4. Clients: a grid table with real AR/limits (an overage shown in red); open a client → a 360 card (metrics, animated tabs, contacts).
  5. Analytics / Catalog / Assistant / operational sections — check against the screenshots; role switching on Home and tab switching in the 360 view are animated.
