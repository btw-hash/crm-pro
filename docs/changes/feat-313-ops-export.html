#313 · Working CSV export for operational tables

The "Export" button (previously dead) downloads the current table honoring the active filter.

What changed

Added a shared client component ExportButton: on click it builds a CSV (delimiter ; + BOM — special characters and columns open correctly in Excel) and downloads the file. The filtered rows are exported (what's currently on screen, honoring ?filter= from #312). Empty table — the button is disabled.

Before → after

Downloads a CSV of the current table (honors the filter), file name matches the screen.
