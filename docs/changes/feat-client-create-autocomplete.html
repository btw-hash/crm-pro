Client creation + autocomplete in the deal form

Branch feat/client-create-autocomplete · 523 tests green · typecheck + lint + format clean

What changed

  • Client creation — a "+ New client" button on /clients (available to managers and head of sales). Opens a modal: name (required), city, EIN. The client appears in the list immediately.
  • Autocomplete client search in the new deal form: the "Client" field was replaced with a combobox that filters as you type (client-side over the passed-in list, no new requests). Keyboard navigation: ↑↓ arrows, Enter, Esc.
  • Inline client creation from the deal form: if you type a name that's not in the list, a "+ Create client '...'" option appears. Clicking it expands an inline block with city/EIN fields; the client is created automatically together with the deal.
  • New use case createClient (application layer) + port ClientRepository.create + implementation in InMemoryClientRepository. 5 TDD tests.
  • Clean architecture is respected: the domain has no next/react/infra. The composition root is extended additively.

Before → after

Before

Clients couldn't be created through the UI. The new deal form had a plain <select> with no filtering: with 25+ clients it was hard to find the right one.

After

On /clients — a "+ New client" button with a modal. In the deal form — a combobox with instant filtering; if the client doesn't exist — create them right from the form with no navigation.

Repro steps

1. Creating a client on /clients
  1. Open /clients (role head or mop).
  2. The "+ New client" button in the list header.
  3. Fill in the name (required), city, EIN → "Create client."
  4. The client appears in the list.
2. Autocomplete in the new deal form
  1. Open /deals → the "+ New deal" button.
  2. In the "Client" field, start typing a name — the list filters by substring (case-insensitive).
  3. Select a client by clicking or with ↑↓/Enter.
3. Inline client creation from the deal form
  1. In the same modal, type the name of a client that doesn't exist.
  2. A "+ Create client '...'" option appears in the dropdown — click it.
  3. A "New client" block expands with city/EIN fields.
  4. Fill in the deal name, click "Create deal" — the client and the deal are created atomically.

Hot files: composition-root.ts (additive, +1 line in the container), create-deal-modal.tsx (replaced <select> with a combobox + inline block).
