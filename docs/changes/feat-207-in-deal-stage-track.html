Move a deal along the pipeline — right from the card

+ a reminder if the current stage's action hasn't been completed

What was done (#207)

  • The deal card now shows a pipeline track (completed / current stage) and transition buttons — a deal can now be moved without going through the board.
  • The buttons only show valid transitions and rollbacks; after clicking, the card updates immediately and the new stage's section unlocks.
  • If the current stage's action hasn't been completed — ⚠ a reminder (audit not done / samples not requested / test act not recorded). This is a hint, not a block — the decision is up to the person.

How to verify

  1. Open a deal at the "Audit" stage (e.g. deal-4).
  2. Under the heading — the track (Qualification ✓ → Audit → …) and a reminder "⚠ Audit hasn't been done yet".
  3. Click "→ Request a test" — the stage changes, the "Test batch / samples" section opens, and the reminder switches to "Samples haven't been requested yet".
  4. The "↩ Audit" button rolls back to the previous stage.
