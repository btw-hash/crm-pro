Revived the filters on the "Clients" page

fix(clients) · closes #301 · branch fix/clients-filters

What changed

  • The All / Key / Debtors / New pills on /clients showed counters, but clicking them did nothing — there was no state, no handlers, no URL parameter. On a demo this stands out immediately (dead buttons).
  • This is now a working server-side filter through the URL ?filter=: clicking a pill reloads the list already filtered (SSR), the active pill is visually highlighted, and the link can be copied and shared — it opens to the same slice.
  • Filtering reuses exactly the same predicates used to compute the counters ("high" priority = Key, credit limit exceeded = Debtors, no deals = New) — a pill's counter always equals the number of rows it shows.
  • The predicates were pulled out into a pure domain module src/domain/client/client-filter.ts — the same filter will go on the operational screens too (a shared filter, #321).
  • The warm theme of the pills (classes, colors, shape) is untouched.

Before → after

Item Before After
Clicking the "Debtors" pill Nothing happens — the list doesn't change Only debtors remain in the list (credit limit exceeded)
"Key" / "New" / "All" pills Dead — just a counter number Filter: key accounts (A) / no deals / the whole list
Active pill "All" always highlighted, even without filtering The selected one is highlighted Debtors All
Direct link /clients?filter=debtors Opened the full list (parameter ignored) Opens the already-filtered debtor list
Pill counter vs. results Counter was computed separately from the (missing) filtering One source of truth — counter = number of rows returned

Repro steps

  1. npm run dev, log in as Head of sales (balances/debtors visible).
  2. Open Clients (/clients).
  3. Click the "Debtors" pill → the list keeps only clients over their credit limit; the "Debtors" pill is highlighted dark.
  4. Check "Key" (only "high" priority), "New" (only clients with no deals), "All" (full list).
  5. Copy the address /clients?filter=debtors into a new tab → the list is immediately filtered (the slice is shareable via link).

Verified

  • npm run verify green (118 files, 663 tests).
