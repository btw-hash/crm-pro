360 deal card — stage workspaces (PR6, steps 6b–6d)

Continuation of the 360 deal card (after the 6a shell). Three stages got working areas matching the "CRM Pro UI" reference.

6b · "Qualification" workspace

Before: at the "Qualification" stage the card only showed "next step" — there was nowhere to record the client profile/need/potential.

After: a checklist of 5 collapsible sub-steps — "Profile and segment", "Need and pain point", "Decision-maker and contacts", "Potential", "Terms and credit risk" — each with fields and a "Done" button; the sub-step number turns into a checkmark once filled in. Data is saved to a new deal_qualifications table (additive migration). The "Recognize document (AI)" and "Dictate" buttons are "coming soon" stubs (AI/voice will be wired up in a separate step).

6c · "Testing" workspace (report → document)

Before: disconnected blocks for the technologist request and the voice-dictated report.

After: a single bento workspace: a list of saved test-report documents (date, product · dosage, "Success/Not successful" chip), then a "Test report" card with dictation (reuses the existing composer) and a note that "the report will be saved as a deal document", with technologist requests below.

6d · Completion — order ungated

Before: the "Customer order" in ERP could only be created if a completed deal had its outcome set to "Won" — hence the self-contradiction "the deal is 'Completed' but the order requires 'Won'" (complaint #397).

After: the order can be created for any completed deal; the "Won/Lost" outcome became an optional note (collapsed into "Mark deal outcome (for analytics)") and no longer blocks the order. The credit limit/payment terms check (#34) is unchanged. Win rate in analytics is still calculated from the outcome.

Verification

  1. Open a deal at the "Qualification" stage (e.g. initial qualification) → the "Qualification" section with 5 sub-steps; expand a sub-step, fill it in, click "Done" → the number turns into a checkmark.
  2. Open a deal at "Testing" → the "Technologist request and test report" section: the report card with dictation; if a report exists — a document row with a result chip.
  3. Open a completed deal → the "Customer order (ERP)" section shows the order form immediately (no "Won" requirement), with the payment terms limit; "Mark deal outcome" is collapsed and optional.
