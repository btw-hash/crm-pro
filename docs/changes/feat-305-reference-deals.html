5 reference end-to-end deals

At every stage you can see real intermediate artifacts — audit, samples, test act, proposal, order, history, tech requests, notifications · #305

What was done

  • Added 5 curated end-to-end deals (deal-ref-1 … deal-ref-5) for demoing to leadership. Open a deal → every completed stage shows filled-in data instead of "not done".
  • Together they cover every stage of the new pipeline (#357): qualification → audit → test_requested → testing → quote → completed — and both outcomes (Won Lost).
  • Per-stage artifacts: an audit checklist (equipment/pain points/decision-maker), a sample request (product, quantity, assigned technologist), a test act (product/dosage/result), a rich feed (calls/visits/notes/tasks + system events for stage changes), a tech request in the shared queue /tech-queue, a next step, and notifications.
  • The data is realistic and connected: our bakery/confectionery clients from the directory, our ingredient products, prices and stock — from the catalog/mock ERP (the proposal is computed live using each client's individual prices). Everything is deterministic (no Date.now/Math.random), with no real PII (passes the guardrail).
  • The 25 existing demo deals were left untouched — they continue to intentionally show gaps ("no next step", "audit not done"). The reference deals are separate "golden" stories.

How to view it in the browser

  1. Sign in as the head of sales (alexander) — they see every deal in the department.
  2. Open the /deals section (the pipeline board).
  3. Find any of the reference deals by the name "Reference: …" (Sunrise Bakery Co., Sweet World Confections, Warm Bread Bakery, ConfiLux Confectionery, Baltic Trading Co.).
  4. Open the card and walk through the pipeline track: every completed stage's section shows filled-in data (audit / samples / test act / proposal), and the current stage shows its actions. The "Activities" tab has a rich feed + the next step.
  5. Open /tech-queue — the tech requests for REF-3 (in progress) and REF-4 (open) are visible there.
  6. The notification bell: REF-1 (win notification to the head of sales), REF-2 (proposal reminder), REF-3 (test completed), REF-4 (new tech request).

Note: the proposal and prices/stock are pulled live from the catalog/mock ERP using the client's individual prices — the numbers aren't made up and aren't stored in the seed.
