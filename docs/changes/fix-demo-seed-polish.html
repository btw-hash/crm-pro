Demo seed polish: a realistic win-rate + a non-empty add-on request list

Branch fix/demo-seed-polish · demo data (seed) only, business logic untouched.

What changed

1. A manager's win-rate is no longer 100%.

Manager Daniel Owens had only won completed deals in the demo data, so "Funnel conversion" showed an unrealistic 100%. Added one completed lost deal.

Before → win-rate 100% (2 won / 0 lost)

After → win-rate ≈ 67% (2 won / 1 lost)

2. The "Add-on requests today" list is no longer empty.

On the add-on requests screen (/shipments/additional), the list of today's entries was always empty — there was no demo data for add-on requests. Added 2 add-on requests with a dynamic shipment date (computed at seed time) so they always fall into the "today" filter.

Before → "No add-on requests for today."

After → 2 add-on requests (Union Grocery Wholesale / Sweet World Bakery), tied to request REQ-2026-0006.
