A new process appears on the board immediately

Create a process → the card shows up on the "Processes" board without a page reload

What changed

  • After creating a process ("New process" → "Create process"), the card now appears on the board right away in the "Qualification" column. Previously it was invisible until you refreshed the page manually (F5) — it looked like the interface had "frozen".
  • Cause: the board kept its process list in local state, captured once when the page opened, and didn't pick up fresh data from the server after a create. Now the board syncs with the server on every update (creating a process, a confirmed card move between stages).
  • Dragging cards between stages still works as before (the optimistic update isn't needlessly reset).

Before → after

Step Before After
Created a new process The board doesn't change, no new card The card is immediately in the "Qualification" column
To see the process Refresh the page manually (F5) Nothing to do
Feel "The screen froze" Instant feedback

How to verify

  1. Open the Processes section.
  2. Click + New process.
  3. Pick a client from the dropdown list (start typing a name and click the suggestion, or "+ Create client "…""), fill in "Process name", click Create process.
  4. Confirm: the modal closed and the new card is immediately visible in the "Qualification" column — without reloading the page.
  5. Edge case: drag a card to the neighboring stage — the move persists, the board doesn't "jump".
