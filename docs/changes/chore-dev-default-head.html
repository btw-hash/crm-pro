Dev: signing in without a session now defaults to Head of Sales

localhost with no login shows the entire product (all sections) · dev only

What changed

  • In dev, when login is optional (no session), the default user is now Alan Peterson (Head of Sales) instead of Daniel Owens (Sales Rep).
  • The Head of Sales sees ALL sidebar sections, so localhost now demonstrates the entire product right away: Procurement, Shipments, Packing, Defect Warehouse, Tech Queue, Assistant.
  • To sign in as a specific role — use /login (quick buttons) or "Switch". In production, sign-in is required and this flag is ignored — prod behavior is unchanged.

Before After

How to verify

  1. If a session is still active in the browser (a name shows in the header) — click "Sign out".
  2. Open localhost — the header shows "Alan Peterson · Head of Sales", the sidebar has 11 sections.
  3. Use the "Switch" button to switch to Sales Rep/Technologist/Buyer and compare permissions.
