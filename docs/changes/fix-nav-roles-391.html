#391 · Navigation and Tab Visibility by Role

Assistant available to Manager · Deals only for Head of Sales/Manager · Global search Ctrl+K temporarily disabled

Summary of changes

  • [3] The "Assistant" tab is now available to the Manager role (previously Head of Sales only).
  • [18+26] The "Deals" tab is now restricted to the Head of Sales + Manager roles. Technologist, category manager, accountant, and logistics no longer see the tab and no longer get a 404 on direct navigation.
  • [4] Global search Ctrl+K is temporarily disabled: the CommandPalette component has been unmounted from the layout, and the search button has been removed from the topbar. The component file stays in the repo — it can be turned back on with a single mount.
  • [2] The collapse-animation bug — not reproduced at the code level; no fix made (see the "Deferred" section).

Before → after: global search Ctrl+K [4]

Before

The <CommandPalette /> component was mounted in src/app/layout.tsx. The search button (magnifying-glass icon) was shown in the topbar and dispatched a cmdk:open event. Pressing Ctrl+K opened the palette on any page.

After

<CommandPalette /> has been removed from the layout. The magnifying-glass button has been removed from AppTopbar. The file src/app/_components/command-palette.tsx stays in the repo unchanged — search can be turned back on with a single mount.

Repro steps

Assistant — Manager role

  1. Sign in as a user with the Manager role.
  2. Confirm the "Assistant" icon is visible on the left rail (collapsed sidebar).
  3. Expand the sidebar — the "TOOLS" group should include an "Assistant" row.
  4. Open the tab — the /assistant page opens.

Deals — technologist/category manager/accountant/logistics role

  1. Sign in with the technologist role (or category manager/accountant/logistics).
  2. Confirm the "Deals" tab is absent from the rail and from the expanded sidebar panel.
  3. Direct navigation to /deals should lead to a 403/redirect page, not a 404.

Deals — Head of Sales and Manager role

  1. Sign in with the head or mop role.
  2. Confirm "Deals" is visible in the sidebar and navigating to /deals works.

Search Ctrl+K — disabled

  1. Sign in under any role.
  2. Confirm the magnifying-glass button is absent from the topbar.
  3. Press Ctrl+K — the palette does not open.
