#299 · Login without credential autofill

The login/password fields no longer show real demo credentials and no longer get autofilled by the browser.

What changed

The login fields showed real demo credentials as placeholders (a.peterson@millbrookfoods.com / demo1234) and were picked up by the browser's autofill. The placeholders were replaced with neutral ones ("Email" / "Password"), and autoComplete is now disabled. The quick-login role pills are still there — they don't fill the fields, they log in directly (handy for a demo).

Before → after

Before

The fields showed real credentials in gray — a.peterson@millbrookfoods.com and demo1234; the browser offered autofill.

After

Neutral placeholders "Email" / "Password"; autofill disabled. Quick role login is still in place.

Repro steps

  1. Log out → open /login.
  2. Make sure the fields hold no real credentials, only "Email" / "Password".
  3. Enter credentials manually → login works. The "Head of sales/Manager/…" pills also log in.
