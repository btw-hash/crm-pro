AI product descriptions in the catalog

AI drafts descriptions ahead of time, tagged "AI-generated" with a source link

What was done (closes #213)

  • AI generates reference product descriptions ahead of time (in a batch, not in real time) and stores them separately.
  • In the catalog, the description shows a 🤖 AI-generated tag and a "source →" link — a human reviews/edits it.
  • The data isn't sensitive (name/category/benefits) → a general-purpose AI provider is allowed; the PII guardrail (#179) lets it through. The source link is a search by name (not a made-up AI URL).
  • The "Generate" button is available to the category manager/head of sales; re-running it leaves already-generated descriptions untouched.
