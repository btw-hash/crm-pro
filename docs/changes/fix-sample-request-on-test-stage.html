Test sample request at the "Test request" stage

branch fix/sample-request-on-test-stage · per client signal (the form didn't let you request a sample)

There was a bug (a real workflow didn't work)

The "Test batch / samples" form with a "Request test" button is shown when the deal is at the "Test request" stage. But the domain action requestSample required the ability to transition into "Test request" — which is only allowed from "Audit". The result: the form was shown where the action would be rejected, and clicking it produced "You can request a test only from the 'Production audit' stage." Through the UI, a sample could not be requested at any stage (in the demo, samples only existed from seed data).

After

Requesting a sample is now allowed directly at the "Test request" stage itself — that's exactly what this stage is about. The sample is reserved and assigned to a technologist, the stage doesn't change (the deal is already there). The old path is preserved: a request from "Audit" still moves the deal to "Test request".

  • from "Production audit" → reservation + transition to "Test request" (as before);
  • already at "Test request" → reservation without a stage change + a "Sample requested" event in the timeline.

Repro steps

  1. Open a deal at the "Test request" stage (e.g. "DeLuxe Confections").
  2. In the "Test batch / samples" block, pick a product and quantity.
  3. Click "Request test (reserve sample)".
  4. The sample is reserved, appears in the list, a technologist is assigned; the stage stays "Test request". No error.

Verified in the browser (REF-4, "Test request"): no error occurred, samples went from 1 → 2, the stage stayed "Test request". npm run verify green (791 tests, +2 new for requesting from this stage).
