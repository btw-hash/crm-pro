Inline editing of deal fields

Click a value in the "Overview" → edit it in place → Enter saves. No "Edit" form.

What changed

  • Three "Overview" fields in the deal header can be edited in place: Name (text), Deal goal (select), Owner (manager select).
  • Clicking a value turns it into an input/select. ↵ Enter saves, esc cancels and restores the original value. No separate "Edit" mode is needed for this.
  • Optimistic: the new value shows immediately, without waiting for the server. If the server rejects the edit (no permission, empty value) — the value rolls back to the original and an error message is shown.
  • Respects the owner boundary (RBAC): a sales rep edits only their own deals; on someone else's deal the fields render as static text (the same check as deal editing).
  • Under the hood — reusable InlineEditField / InlineEditSelect components, ready to be embedded in the side drawer too. No domain logic is duplicated — the edit goes through the existing deal-update use-case.

Before → after (changing a deal's goal)

Before A separate "Deal goal" form with a dropdown and a "Save" button under the header; a full edit went through the "Edit" modal with a multi-field form. An extra "Save" click for every single field.
After Click the goal value → pick from the list → Enter. The value is saved. No "Save" button, no separate edit mode.
The deal domain has no "priority" field (as in the original task description) — it doesn't exist in the model. Instead, Owner is edited inline (a real, meaningfully editable field that actually exists). "Next step" is a task/activity (set via the quick-action from TASK-5), not a deal field, so the inline set covers three deal fields: Name, Goal, Owner.

Why (vs legacy CRMs)

Legacy CRMs still open a separate edit form for any small field change — a marker of a legacy interface. Click-to-edit inline (as in Attio / Linear / Notion) is a 2024+ pattern: fewer clicks, no switching into an "edit mode", the edit feels instant thanks to the optimistic update.

How to verify

  1. Open Deals (/deals) and open any deal.
  2. In the header below the buttons — a block of fields Name / Deal goal / Owner. Values get underlined on hover (a marker that they're clickable).
  3. Click the Deal goal value → a dropdown appears → pick another goal → Enter. The value changes immediately; after reloading the page it's still saved.
  4. Click Name → the field becomes an input → change the text → Enter saves it.
  5. Check cancellation: enter edit mode on any field, change the value, and press esc — the edit is canceled, the original value stays, nothing is saved.
  6. Edge case: clear Name completely and press Enter — the server rejects it (the name cannot be empty), the value rolls back to the original, an error message shows next to it.
  7. RBAC: as a sales rep, open someone else's deal — the fields render as plain text, they don't enter edit mode (your own deals — still editable).
