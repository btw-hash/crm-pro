#303 · Tasks → Processes, Activities → Tasks

Unified UI terminology: the funnel board is now "Processes", and the actions inside a card are "Tasks".

What changed

By decision: what used to be called "Tasks" (the funnel board, a.k.a. "the deal") is now "Processes"; and "Activities" (calls/meetings/notes inside a card) is now "Tasks". Only visible text and error messages changed: headings, the menu item, buttons, labels, placeholders, error text. The code, routes, and data model were left alone (internally it's still deal) — behavior doesn't change, only the labels.

Glossary — before → after

Before After Where
Tasks Processes menu item, section heading, board
New task New process button and create dialog
Task name Process name create/edit form
Task card Process card right-hand panel
Tasks by stage Processes by stage home page, analytics (donut chart)
Urgent tasks · My day — tasks Urgent processes · My day — processes home page (tiles)
Outcome of a completed deal Outcome of a completed process badge on the board card
Activities Tasks tab/feed in the card
Activity feed · No activities yet Task feed · No tasks yet card, client, panel
Dictate an activity (AI) Dictate a task (AI) voice input in the card

Wording was adjusted throughout so messages read naturally with the new terms (e.g. "unavailable", "won", "not found", "completed" now refer to a "process" instead of a "task" wherever the meaning changed).

Left as-is (on purpose)

  • The activity type in the "Type" dropdown — the value "Task" (this is an activity subtype, not the board).
  • The tech-request placeholder "Describe your question or task for the technologist" — here "task" means an assignment for the technologist, not the board.
  • "Next step" / "No next step" — a separate concept, not renamed.
  • Code, routes (/deals), the Deal model, internal comments — left unchanged.

How to verify

  1. On the left in the menu — the item "Processes" (was "Tasks"). Open it → heading "Processes".
  2. The "New process" button → the dialog has a "Process name" field.
  3. Open any process (card) → the "Tasks (N)" tab, the "Dictate a task (AI)" block, "Task feed".
  4. Home page and Analytics → the "Processes by stage" donut; "Urgent processes", "My day — processes" tiles.
  5. Client card → "Task feed".

Verified: npm run verify is green (789 tests), every screen renders live with the new labels; the old "Tasks" (board)/"Activities" are gone from all visible spots.
