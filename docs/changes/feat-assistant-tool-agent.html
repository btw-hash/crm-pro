Head of sales assistant — now a tool agent (ReAct)

The AI chooses tools itself (CRM data / web search) and can combine them

What was done (#281 — assistant evolution)

  • The "ask CRM or search the web" routing is no longer decided by a fragile regex (WEB_SEARCH_RE removed). The decision is made by the AI itself — as a ReAct agent.
  • Two tools: query_crm — a snapshot of our data (deals/clients/managers/AR/pipeline, numbers computed by code); search_web — search on the open internet (suppliers, market, new companies).
  • The agent can combine both tools (e.g. first check the market on the web, then cross-reference our deals) and then give a single answer. The answer's source can now be "CRM," "web," or "CRM + web."
  • PII guard: the outgoing web query is stripped of phone numbers (sanitizeWebQuery), the full CRM snapshot never goes out to the internet — only the public search query does.
  • Architecturally: the agent is built as a loop over instructed JSON (extractJson), without native function-calling — provider-neutral (Claude/OpenAI).

Before → after

Head of sales assistant Before After
Who decides "CRM or web" A fragile regex on the question's wording (easy to miss) The AI agent chooses the tool itself based on the meaning of the question
Combining sources Impossible — strictly one or the other Possible: web + CRM in one answer (source "CRM + web")
Web query and PII The question text went to search as-is It's stripped of phone numbers; the AI is instructed not to include internal data
Answer footer label "Web search" or "CRM snapshot" Added "CRM + web search" for combined answers

How to verify

  1. Log in with the Head of sales role and open the "Assistant" section.
  2. Ask about our data: "Which deals are stalled with no next step?" → an answer from the CRM snapshot, footer reads "CRM snapshot: N tasks …".
  3. Ask about the outside world: "Find new ingredient suppliers" → an answer from web search, footer reads "Web search" + a list of source links.
  4. Ask a combined question: "Compare the cocoa market with our active deals" → the agent uses both web and CRM; footer reads "CRM + web search …" and links.
  5. Privacy check: even if a phone number slips into the question, it won't make it into the outgoing search query (stripped by the PII guard).

NB: AI answers depend on the provider (on the demo stand — a deterministic stub: a 2-step agent that picks a tool by keyword and answers with a summary).
