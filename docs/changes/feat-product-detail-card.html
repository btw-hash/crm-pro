Catalog: product card on click — ERP data + AI description

Issue #375 · branch feat/product-detail-card · builds on #308

What changed

  • In the catalog table, clicking a row now opens the product card (/products/[id]) — the same pattern as the client card /clients/[id].
  • The card shows ERP data: the recommended price (margin — only for commercial roles), available stock with a status badge, shelf life, and packing.
  • An "Open in ERP" button (ERP window) — same as on the client card.
  • An AI description block (text + source link) and a Sales Kit "Advantages" section; "Copy for client" and "Schedule client outreach" actions (Manager/head of sales).
  • Selection checkboxes and row action buttons don't open the card.
  • Numbers/stock come from the ERP (deterministic); AI is only responsible for the description text.

Before → after

Before
  • The SKU table (#308) — row data, but no detail view.
  • There was nowhere to expand ERP data and the AI product description.
After
  • Clicking a row → the full product card with ERP metrics.
  • AI description + "Open in ERP" + Sales Kit — same as the client card.

Repro steps

  1. Open /products as a commercial role (on localhost — Head of sales).
  2. Click any product row (not the checkbox/button) → the product card opens.
  3. On the card: name + stock status, SKU/category, ERP metrics (price/stock/ shelf life/packing), the AI description block, advantages, "Open in ERP".
  4. Click "Open in ERP" → the ERP window (in production, where the window address is set).
  5. "Back to catalog" returns to the table.
  6. Verify: clicking a row's checkbox selects it and does NOT open the card.

Verification
