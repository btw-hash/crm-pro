What changed

Bug item 20 Completed tech requests disappeared from the Manager's card

The listActive() method only filtered open|in_progress, so done requests vanished from the deal card as soon as the technologist finished the work.

Item 17 Technologist status on the Manager's card at the "Testing" stage

At the testing stage, the Manager's drawer now shows a colored badge with the status of the latest request: "Waiting" / "In progress" / "Done".

New page Technologist kanban board /tech-board

Three columns: Open / In progress / Done. Each card is a clickable link that opens a side drawer. Only available to the technologist and head roles.

Drawer Request side panel with a flow: voice → AI draft → act → Done

At in_progress status, the technologist pastes a voice-note transcript → AI generates a draft test act → a field editor → "Save act" → "Done". Closed with Escape or a click outside the panel.

Repro steps

Bug item 20 — request history on the Manager's card

  1. Log in as a Manager (e.g. owens).
  2. Open a deal that has a tech request with status done.
  3. Confirm the completed request is shown in the "Tech requests" section (previously it disappeared).

Item 17 — technologist status in the Manager's drawer

  1. Log in as a Manager.
  2. On the process board, click a deal at the Testing stage.
  3. In the side drawer that opens, find the "Technologist" row with a colored badge (yellow — waiting, green — in progress, gray — done).
  4. For deals at other stages, the "Technologist" row is not shown.

Technologist board /tech-board

  1. Log in as a technologist (e.g. kent) or head of sales (head).
  2. In the side menu, click "Technologist board" (flask icon).
  3. Confirm 3 columns are shown: Open / In progress / Done with request cards and counters.
  4. Click any card — ?req=<id> is added to the URL, and a side drawer with the request details opens.
  5. Close the drawer: press Escape or click outside the panel.

Voice → Act flow (for an "In progress" request)

  1. Log in as a technologist.
  2. Open /tech-board, click a card with status "In progress".
  3. The panel shows a "Transcript (voice note)" field.
  4. Paste the transcript text and click "Generate act draft".
  5. AI returns filled-in act fields (product, dosage, parameters, result).
  6. Edit the fields if needed, click "Save act".
  7. After saving, a "Done" button appears — click it to move the request to done.
Migration: Not required. The status field (String) in the tech_requests table already stores open / in_progress / done. The quantity/unit fields were added by a parallel branch.
