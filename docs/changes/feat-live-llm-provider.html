A real, budget-safe LLM for the public demo

OpenRouter behind the existing LlmProvider port — never crashes, never runs up a bill

What changed

  • New OpenRouterLlmProvider implements the existing LlmProvider port (AI_PROVIDER=openrouter) — same contract as the Claude/OpenAI adapters, over plain fetch, no SDK.
  • Every call is hard-capped at 1024 output tokens, regardless of what the caller asks for.
  • New BudgetCappedAiGateway decorator: after 200 calls in a UTC day, further requests are served by the deterministic stub instead of the real model, with an honest "Demo AI budget exhausted for today" note — never a failed request, never an unbounded bill.
  • A missing OPENROUTER_API_KEY degrades to exactly the current stub behavior, even with AI_MODE=live — never crashes the app.
  • Treated as a global-contour provider (same as Claude) under ADR-0007 — the existing ContourGuardLlmProvider/PseudonymizingLlmProvider/usage-tracking pipeline applies unchanged.

How to verify

see caveat below
  1. .env: AI_MODE=live, AI_PROVIDER=openrouter, OPENROUTER_API_KEY=<key>. Restart npm run dev.
  2. Open any deal → the voice-to-act composer has a sample transcript loaded → "AI recognize → draft report" — a structured (extractJson) call.
  3. Log in as the head of sales (a.peterson / demo1234) → /assistant → ask "Which deals are stalled?" — routes through the CRM snapshot, phrased as free text (completeText).
  4. Remove OPENROUTER_API_KEY and restart — the app must keep working exactly as it does with AI_MODE=stub, no crash.

⚠ Not run against the real OpenRouter API — no OPENROUTER_API_KEY was available in the environment this PR was built in. The adapter and the budget fallback are covered by unit tests (mocked fetch, injected clock); the 4 steps above still need a real key run once before this ships to the live demo. See docs/LLM_SETUP.md.

Under the hood (for developers)

  • src/infrastructure/ai/llm/openrouter-llm-provider.ts — the LlmProvider adapter (OpenAI-Chat-Completions-compatible request/response shape, same as OpenAiLlmProvider); src/infrastructure/ai/budget-capped-ai-gateway.ts — the AiGateway decorator with the daily counter.
  • Wired in composition-root.ts: buildOpenRouterAiGateway short-circuits to the stub on a missing key, otherwise builds the same Pseudonymizing → ContourGuard → UsageTracking chain as the other providers, then wraps the result in BudgetCappedAiGateway.
  • Default model meta-llama/llama-3.3-70b-instruct:free — zero marginal cost; override with OPENROUTER_MODEL.
  • 14 new unit tests (provider + gateway) plus env-parsing and assertProviderCompliant coverage — 1031/1031 total, npm run verify and npm run build green.
