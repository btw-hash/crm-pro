chore: close the "tech queue" loop — manager notification (Closes #311)

When a technologist completes a tech request, the responsible manager now gets a notification in the /notifications feed. The deal stage is left untouched — this is purely informational.

Before → after

Before After
The technologist clicked "Done" → the request moved to done, and the manager never found out. The loop had to be closed manually (a phone call / checking a list). The technologist clicks "Done" → the responsible sales rep instantly sees a notification in the /notifications feed: "The technologist completed the request for deal '…'. Review the result and plan the next step."
The deal stage didn't change. The deal stage still doesn't change automatically — the manager makes that call themselves.

Repro steps

  1. Sign in as the technologist (kent / demo1234). Go to the Tech Queue (/tech-queue).
  2. Take the request into work with the "Take into work" button — the status changes to "in progress".
  3. Click "Done" — the request disappears from the active queue.
  4. Sign out and sign in as that deal's responsible manager (e.g. owens / demo1234).
  5. Go to Notifications (/notifications) — a notification has appeared in the feed: "The technologist completed the request for deal '…'. Review the result and plan the next step."
