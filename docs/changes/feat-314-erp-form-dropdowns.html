#314 · ERP dropdowns in request forms (instead of free-text)

Nomenclature / unit of measure / pack size in the packing, defect, and add-on request forms — now sourced from the ERP catalog.

What changed

In the "New request" forms (packing, defect warehouse, add-on request), the Nomenclature, Unit of measure, and Pack size fields were free-text — you could type anything. Now they're <select> elements populated from the ERP nomenclature (catalog products): you can't enter arbitrary garbage, values are consistent with the catalog. Pack size was added to the nomenclature (the field was ready since #292, there was no data) — 9 formats.

Before → after

Before

Text fields: "Chocolate…", "kg", "1 kg" — free-text, typos/garbage.

After

ERP dropdowns: product (9), pack size (9), unit (kg/pack). Only valid values.

Repro steps

  1. Open "Packing" → "New request" form: Product/Source-Target pack size/Unit — dropdowns.
  2. Select a product from the nomenclature, a pack size from the list, a quantity → "Create" → the request appears in the table.
  3. Same in "Defect warehouse" (product, unit) and "Add-on requests" (nomenclature, unit).
  4. Verified headless: product options=9, pack sizes=9, units=2; submitting via select creates a request (4 → 5 rows).
