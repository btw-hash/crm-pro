Deal card — fields for the current stage only

#207 · branch feat/deal-stage-sections · epic #204 (2026-06-25 demo review)

What changed

  • The deal card ("Overview" tab) no longer shows every field at once in one long sheet. Sections expand based on the deal's stage.
  • The current stage — the section is active (forms and actions are available).
  • Past stages — read-only: filled-in data is visible (audit, samples, test act), marked with a "completed" badge, no forms.
  • Future stages — collapsed into a hint "🔒 … — unlocks at the '…' stage".

Before → after

Before

Audit, samples, technologist request, test act, proposal, letter, order — all at once, in a long scroll regardless of stage. The manager drowned in irrelevant fields.

After

Only the current stage's section is visible + a brief past (read-only). The future is collapsed. Exactly one active section per stage.

Stage → active section mapping

  • Production audit → the "Production audit" section (audit form)
  • Test request → "Test batch / samples" (sample reservation)
  • Testing → "Technologist request and test act"
  • Proposal calculation → "Proposal and letter"
  • Won → "Customer order (ERP)"

A technologist (with no access to commerce) still doesn't see the proposal/order sections — same as before.

Repro steps

  1. Open http://localhost:3003/deals (logged in as the head of sales).
  2. Open a deal at an early stage (e.g. "Qualification"/"Audit") — future sections are collapsed into "🔒 unlocks at stage…", only the current stage's section is active.
  3. Open a deal at the "Testing" stage — "Technologist request and test act" is active; audit and samples above show a "completed" badge (read-only).
  4. Open a won deal — every section shows "completed", "Customer order (ERP)" is active.
  5. Expand any collapsed future section — it only shows a caption inside, no forms (it unlocks when the deal reaches that stage).
