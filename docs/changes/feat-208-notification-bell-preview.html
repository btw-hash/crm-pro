Notification bell — now with text

A preview of recent notifications right from the topbar, no navigation needed

What was done (part of #208)

  • The bell used to show only the count of unread notifications. Now, clicking it expands a preview: the text of recent notifications + time + an "open deal" link.
  • Unread ones are on top and highlighted; there's a "Mark all read" button and an "All notifications →" link.
  • Everyone only sees their own notifications (owner boundary by recipient).

Before → after

Topbar bell Before After
What's visible Just the number "0"/"N", no content Text of recent notifications + time + a link into the deal
Action Only navigating to the notifications page "Mark all read" right from the dropdown; "All notifications →"

How to verify

  1. Sign in as a user with notifications (e.g. Daniel Owens).
  2. Click the 🔔 in the top-right corner.
  3. A list opens: "Test for deal … completed" (unread, highlighted), "Client … confirmed they're ready …" + time and "open deal".
  4. "Mark all read" resets the counter; "All notifications →" opens the full page.

NB: in dev, switching users via /login currently doesn't work (bug #205) — to verify under a specific role, the dev default is temporarily changed.
