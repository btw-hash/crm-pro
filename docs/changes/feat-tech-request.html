Repro steps

  1. Log in (owens / demo1234). Open any deal, e.g. deal-2 ("Noirelle chocolate onboarding").
  2. On the Overview tab, find the "Request technologist" block.
  3. Pick a type — e.g. "Production site visit", enter a note, click "Request technologist". "Request sent to technologist." appears below the button.
  4. Go to Notifications (bell) — a notification for the technologists appears there.
  5. Go to the Tech queue (🧪 in the sidebar, /tech-queue). The new request is visible in the list with status "open".
  6. Click "Take" — the status changes to "in progress", the button is replaced with "Done".
  7. Click "Done" — the request disappears from the active queue (status done).
