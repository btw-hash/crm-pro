Catalog → compact SKU reference table

Issue #308 · branch feat/catalog-sku-table

What changed

  • The catalog was reworked from an "online store" look (3-column cards + cart + a "Place order" modal) into a compact SKU reference table — a working tool for the manager, not a storefront.
  • Columns: SKU · name · category · stock · price · expiration · pack size · actions. Margin in the price column — only for commercial roles (showMargin).
  • Search by name/SKU + two rows of filters: by category and by stock status (in stock / low / on order).
  • The cart and order placement were removed entirely.
  • "Copy for proposal" was kept: row checkboxes → a "Selected: N items" panel → a "Copy selected for proposal" button (a list of name+SKU+price to the clipboard). The selection survives a filter change — a proposal can be assembled across different categories.
  • "Schedule client pitch" (launching a new SKU) and "Copy for client" (pitch) were kept as row actions.
  • Price and stock — from the Mock ERP (numbers are deterministic, AI doesn't touch them).

Before → after

Before
  • A 3-column grid of product cards with a large price and an AI block.
  • An "Add to cart" button, cart counter, a cart modal with +/− quantity.
  • A "Place order" button in the modal (storefront shop logic).
  • One row of filters — categories only.
After
  • A dense table: one row = one SKU, many items visible at once.
  • Row checkboxes + a batch "Copy for proposal" panel.
  • No cart and no "Place order" — this is a reference tool.
  • Two filters — category and stock status; search by name/SKU.

Repro steps

  1. Open /products under a commercial role (on localhost — Head of sales).
  2. You'll see the SKU table with SKU/stock/price/expiration/pack size columns and stock-status badges.
  3. Type "vanilla" (or a SKU) into search → the table narrows to matches.
  4. Click a category chip (e.g. "Chocolate") and a status chip ("On order") → rows filter by both conditions.
  5. Check the boxes on a few rows → "Selected: N items" appears at the top.
  6. Click "Copy selected for proposal" → the clipboard gets a list like • Product name (SKU) — $X / kg; the button shows "Copied ✓".
  7. Confirm there's no "Cart" or "Place order" button anywhere.
