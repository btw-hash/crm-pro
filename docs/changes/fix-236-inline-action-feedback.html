Catalog / returns / onboarding actions — clear feedback, no silent failures

AI description generation shows the result; errors don't disappear silently

What changed (closes #236)

  • AI description generation (Catalog): on completion you now see "Done: generated N of M", and on an AI service failure — a soft error right next to the button. Previously a network/LLM failure risked a red 500 overlay, and success gave no feedback at all.
  • Returns and onboarding: actions no longer "swallow" every error silently. An expected failure (e.g. the request was already moved) is a silent no-op, and the list refreshes to the real state right away; an unexpected (infrastructure) error is no longer hidden — it surfaces, so real bugs don't go unnoticed.
  • This wraps up the class of issue from #232 (that one removed 500 overlays; this one adds feedback and careful error handling).

Before → after

Action Before After
AI description generation (success) Nothing visible — did it work or not? "Done: generated N of M"
AI description generation (LLM/network failure) Risk of a red 500 overlay Soft error next to the button, can retry
Return/onboarding: unexpected error Swallowed silently (bug invisible) Surfaces — bug is visible

How to verify (main scenario)

  1. Log in as Alan (Head of sales) or Procurement, open "Catalog".
  2. Click "🤖 Generate AI descriptions".
  3. After completion, "Done: generated N of M" appears under the button (no red overlay).
  4. Descriptions are filled into product cards with an "🤖 AI-generated" tag.
