Sales Kit (price/margin/advantages) + AI product descriptions in Postgres

Issue #377 · branch feat/product-kit-postgres · data fix for #308/#375

What changed

  • Nullable kit columns were added to the products table (kitCategory, kitBenefits, kitMarginPercent, kitRspMinor) via an additive migration (0_init was left untouched).
  • PrismaProductRepository now reads and writes the Sales Kit: it reconstructs ProductKit (the RSP price from minor units via Money), upserting kit fields. Kit stays empty for synced ERP nomenclature.
  • The seed now writes kit data to products and seeds 9 AI descriptions (seedProductDescriptions) — for both Postgres and in-memory mode.
  • Result: production's catalog and product card now show price, margin (by role), advantages, and an AI description with a source.

Before → after

Before (in production)
  • Catalog with no prices (kit wasn't wired to Postgres) — "—" everywhere.
  • Product card: "Description not yet generated."
After
  • Price/margin/advantages visible (kit in the DB), margin — for commercial roles.
  • The card and the table's hover tooltip show the AI description + source.

Repro steps

  1. Open /products as a commercial role (on localhost — Head of sales).
  2. The "Price" column now shows dollar amounts (and — for a commercial role — the margin too).
  3. Click a row → on the product card: "Recommended price", an AI description block with text and a "source" link.
  4. Hover over the name in the table → the tooltip shows the same description.

Verification
