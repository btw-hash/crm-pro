fix(ui) "New request" button on the collapsed sidebar rail

What changed

The collapsed rail (the narrow dark panel) was missing the red "+" "New request" button. In the reference design ("CRM Pro UI") it's there — a red square icon between the hamburger and the navigation — but it was removed in chore #298 and only remained in the expanded panel. Restored it on the rail: for the same roles with create permission (Head of Sales / Manager), opening the same request-creation window.

Before → after

Sidebar state Before After
Expanded panel Full-width "+ New request" button Unchanged
Collapsed rail No create button Red 46×46 "+" square (reference): between the hamburger and the icon list

The "+" button opens the same CreateRequestModal window (Deal / Shipment / Add-on request) as the button in the expanded panel. Visible only to the head / mop roles; server-side permission validation in the actions was not changed.

Repro steps

  1. Sign in as Head of Sales or Manager (in dev, localhost opens as Head of Sales).
  2. Collapse the side menu into the rail (hamburger icon at the top of the sidebar).
  3. See the red "+" button right below the hamburger, above the list of section icons.
  4. Click "+" → the "New request" window opens with a choice of Deal / Shipment / Add-on request.
  5. Sign in as technologist / accountant / logistics / buyer → there is no "+" button on the rail (no create permission).
