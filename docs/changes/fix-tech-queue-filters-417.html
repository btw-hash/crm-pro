Tech queue: filters and export

On the "Tech queue" page (/tech-queue) the filter chips and the "Export" button were dead — plain buttons with no handlers (local FilterRow / OpsHeader). Clicking did nothing.

Before After
Chips (All / Open / In progress / Site visits) decorative, clicking had no effect the shared OpsFilters → ?filter=, the list is actually narrowed server-side (like on the other ops screens)
The "Export" button an empty button the shared ExportButton → a CSV of the filtered requests (;-separated + BOM for Excel compatibility)

The filter logic was extracted into src/app/tech-queue/_lib/tech-queue-filter.ts and covered by tests. open/in_progress — by status, "Site visits" — by the onsite type. The metrics (open/in progress/site visits) are computed across all active requests.

Repro steps

  1. Sign in as a technologist (or head of sales), open "Tech queue".
  2. Click the "Open" chip → the list narrows to requests with status "open", ?filter=open appears in the URL; "Site visits" → only on-site production visits.
  3. Click "Export" → downloads a CSV of exactly the requests visible under the current filter (opens correctly in Excel: client, process, type, note, date, status).
