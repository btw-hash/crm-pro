Command palette — search and navigation with Ctrl+K

Find a client, deal, or product in a second from any screen

What was done

  • Ctrl+K (or ⌘K) opens the palette from anywhere; there's a 🔍 Search trigger button in the header.
  • Fuzzy search across clients, deals, and the catalog + navigation commands (Go to: Clients / Deals / Analytics / Catalog).
  • Keyboard: ↑↓ to select, ↵ to open, esc to close.
  • Search respects permissions (RBAC via a server action): a manager can't find another manager's portfolio.

Why (vs legacy CRMs)

In a legacy CRM, finding the right client/deal means digging through menus and a slow search. Here — press Ctrl+K, type a couple of letters, Enter — you're there. A hallmark of a modern tool (Linear, Notion, Figma, Attio).

How to verify

  1. On any screen, press Ctrl+K (or the "Search" button in the header).
  2. Type part of a name — e.g. "baker" → a list of clients; "glaze" → deals/products.
  3. Use the arrows to select, Enter — go to the record.
  4. An empty query shows navigation commands for the sections.
