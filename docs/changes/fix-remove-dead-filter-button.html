Removed the dead "Filter" button from all lists

fix(ui) · PR #279 · closes #278 · branch fix/remove-dead-filter-button

What changed

  • The "Filter" button (funnel icon) was copy-pasted across 14 screens as an identical block without onClick — clicking it did nothing. In the demo this is noticeable and misleading.
  • All of these screens already have working filter pills (All/Mine/In transit/To process/Growth…), so the dead button was redundant. Removed it from: accounting, analytics, assortment, deals, defects, logist, my-shipments, notifications, onboarding, packing, procurement, shipments (+ additional), tech-queue.
  • In the Catalog, "Filter" is a set of working category chips — those were left alone.

Before → after

Item Before After
"Filter" button in the toolbar of 14 lists Present, but without a handler — clicking does nothing Removed (dead UI cleaned up)
Working filter pills (All/Mine/In transit/…) Present and working Left in place — the only way to filter
The rest of the toolbar (Export/New deal, etc.) Present Unaffected, still in place
"Filter" in Catalog (category chips) Working chips Untouched

Repro steps

  1. npm run dev, sign in as Head of Sales.
  2. Open, for example, Deals and My shipments — the toolbar no longer has the non-working "Filter" button (funnel icon).
  3. Confirm the working filter pills (All/Mine/In transit/To process/…) and the Export/New deal buttons are in place and working.
  4. Open Catalog — "Filter" (category chips) is still there and still filters.

Verified

  • Grepped — no dead "Filter" buttons remain on the lists.
