#211

Rename: "Deal goal" → "Visit goal"

Decision on the contested point

"Deals → Tasks" — NOT implemented.

The deal card (the "Add manually" section, "Type" dropdown) already has an option value="task" labeled "Task" — an activity type. Renaming the "Deals" section to "Tasks" would create a direct terminology collision on the same screen: "Task" as the pipeline and "Task" as an activity type. Only the second part of the issue was implemented — improving the label of the goal field.

What was NOT changed (intentionally)

  • The DealGoal type, the goal DB field, domain entities — unchanged
  • The <dt>Goal</dt> label in the side drawer — a short form, understood from context
  • The command palette entry "Go to: Deals" — that's the section's navigation label
  • The "Deals" section in the sidebar — not renamed (see rationale above)
