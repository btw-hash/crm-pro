"Comment" field on a deal (#393, item 11)

The final item of epic #393. Deals now have a free-text comment — set on creation, edited afterward, visible on the card and side panel.

What changed

  • A new optional domain field Deal.comment + an additive migration add_deal_comment (nullable TEXT, 0_init untouched).
  • The "New deal" form — a "Comment" field (below "Owner").
  • The "Edit deal" form — a "Comment" field with the current value; an empty string clears it.
  • The deal card /deals/[id] and the side panel show the comment if set.
  • Wired through domain → use-cases (create/update) → Prisma repository (read/write).

Reproduction steps

  1. "Deals" → "New deal": fill in the form + enter a "Comment" → create.
  2. Open the deal card → under the stage you'll see a "Comment: …" line.
  3. "Edit" → change/clear the comment → "Save" → the value updates.
  4. Open the deal via the side panel from the board → the comment is visible above the "Task feed".
