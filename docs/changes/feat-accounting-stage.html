Before → after

Before: the shipment chain broke — the manager handed the order to accounting, but there was no one to move it further to the warehouse (the in_accounting stage had no interface).

After: the accountant processes it and hands it to the warehouse → the order reaches the logistics coordinator → the manager sees the updated status. The loop manager → accountant → warehouse → logistics is closed.
