Web search in the head of sales assistant

#216 / #234 · branch feat/assistant-web-search · on top of the assistant chat (#227)

What changed

  • The assistant now answers not only from the CRM snapshot, but also questions about the outside world ("find new suppliers," "who's in the market") — via web search.
  • Routing by the question's text: a query with search triggers goes to WebSearchGateway, everything else — to the deterministic CRM snapshot (as before).
  • The answer shows the source: "CRM snapshot" or "web search" + clickable links to the found pages.
  • Query cost estimation (tokens/$) is kept for web answers too.

Architecture

  • New port application/ports/web-search-gateway.ts + a deterministic stub infrastructure/ai/stub-web-search-gateway.ts.
  • The real provider (Brave Search API) connects through the same port via env WEB_SEARCH_MODE=live — with no change to the use case.
  • PII guard: only the public question text goes to web search; the CRM snapshot (PII/trade secrets) is NOT passed to search.

Repro steps

  1. Log in as the head of sales, open "🤖 Assistant."
  2. Ask "Which deals are stalled?" → an answer labeled "Source: CRM snapshot" (as before).
  3. Click the example "Find new ingredient suppliers" → an answer labeled "Source: web search" and a list of source links.
