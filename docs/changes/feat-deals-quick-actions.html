Quick actions on a pipeline card — log a call in one field

Log an activity and set the next step right from the board, without opening the deal

What changed

  • Hovering a deal card reveals quick actions: + Activity, ⏭ Next step, ⇄ Change stage.
  • Activity opens a mini popover: a type pill (Call / Visit / Note), one "What happened?" field, and a date (defaults to today). ↵ Enter saves, esc closes.
  • Next step — the same popover, but it writes a task with a due date (this is the deal's "next step").
  • Change stage expands the already-existing transition/revert buttons (the transition logic isn't duplicated).
  • The entry appears in the deal's feed right away, with its author and time. Respects the owner boundary: a sales rep can only log against their own deals (the same check as a stage transition).

Before → after (logging a call)

Before Open the deal card → the "Activities" tab → the "Add manually" form → pick a type → enter text → Save → return to the board. 4+ clicks and leaving the page.
After Hover the card → + Activity → type the text → Enter. Hover + 1 click + Enter, without leaving the board.

Why (vs legacy CRMs)

Logging a call is a manager's single most frequent action. In a legacy CRM it's a form on the deal's page with back-and-forth navigation. Here logging it takes seconds right on the board — a win in speed and click count (Close CRM call notes, Pipedrive quick actions).

How to verify

  1. Open Deals (/deals).
  2. Hover over any card — quick actions appear at the bottom.
  3. Click + Activity → pick a type (defaults to "Call") → write "What happened?" → Enter. A "Logged ✓" mark appears.
  4. Open that deal → the "Activities" tab — the new entry is at the top of the feed with your name and time.
  5. Check ⏭ Next step: the same popover sets a task with a due date; the "no next step" mark disappears from the card.
  6. ⇄ Change stage expands the transition buttons (→ / ↩) — the stage changes optimistically, same as with drag-and-drop.
  7. Edge cases: empty text isn't saved (a hint says "Describe what happened."); esc closes the popover without logging anything.
