Live month-by-month sales history in the Mock ERP

The "Revenue by month" chart now shows a curve, not equal-height red bars

What was done (closes #350)

  • The synthetic sales-history generator in the Mock ERP (`tools/mock-erp/data.mjs`, the `salesHistory()` and `purchaseHistory()` functions) now produces different revenue per month, instead of the same amount every month.
  • The period was extended from 6 to 12 months (2025-07 .. 2026-06) — the "Year" and "Half-year" breakdowns on the chart now show a proper curve.
  • The data now encodes trend storylines (stable / growing / decline to zero / a departed SKU / a new SKU) — the same data is read by "Assortment", "Recommendations", and "Procurement", so all the AI analytics get richer, not just one chart.
  • Everything is deterministic (no `Date.now` / `Math.random`) — the demo is stable across runs. The ERP's OData document format is untouched (Ref_Key / Number / Date / the table section / units) — only the amounts / quantities / dates vary by month.

How to verify

  1. Open /analytics (the "Sales Analytics" section).
  2. The "Revenue by month" block — now shows bars of different heights with a readable curve, not 4-6 identical "peaks".
  3. Switch the breakdown to "Year" / "Half-year" — 12 / 6 months are visible with an upward trend and month-to-month swings.
  4. Check "Assortment" / "Recommendations" / "Procurement" — the storylines (S500 decline, new Miroir, departed Topfil) make the hints more meaningful.
