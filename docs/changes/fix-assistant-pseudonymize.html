Head of sales Assistant: client names no longer go to the LLM in plain text

PII pseudonymization wired in for every request (GDPR/CCPA-style) + 3 assistant behavior fixes

What changed

  • PII pseudonymization wired inCloses #282 / #296 — the pseudonymize masking mechanism existed, but the provider was built with empty lists → client/manager/technologist names and company names went to the LLM in plain text. Now the assistant collects them from the CRM snapshot on every request and masks them before sending to the model; the originals are restored in the response. Known Tax IDs are excluded from phone-number detection (#296).
  • Outgoing web query cleanup#282 — previously only phone numbers were stripped from the public search query. Now known client names are stripped too (in case the model still inserts them into the search string).
  • Step limit no longer loses data#14 — when the ReAct loop hit its limit, the assistant returned an empty stub and lost the collected snapshot/web data. Now it synthesizes an answer from the data already collected, and the source stays in the response.
  • Web sources persist in history#15 — opening a conversation from history made the clickable links disappear. Now they are saved with the response and restored on reopen.
  • Empty turns no longer break follow-ups#16 — empty assistant responses leaked into the follow-up context, so clarifications like "and the links?" were interpreted incorrectly. Now empty turns are filtered out.

How to verify (main scenarios)

  1. Log in as Alan (Head of sales) → open "Assistant" in the sidebar.
  2. Pseudonymization (#282/#296): on the live LLM (AI_MODE=live), ask about a specific client/manager by name. The answer is correct (names in place), but placeholders went to the LLM — this behavior is covered by pseudonymize.test.ts and ask-manager-assistant.test.ts (names from the CRM are collected into scope).
  3. Web sources in history (#15): ask "Find new ingredient suppliers" → wait for a response with links → start a "New conversation" → open the previous conversation from the "History" panel → the source links are still there.
  4. Follow-up (#16): in a conversation, ask a clarification "and the links?" after a substantive answer — it's interpreted relative to the real previous answer.
  5. Step limit (#14): reproduced in the test "step limit … → synthesis from collected data" — the answer isn't empty, the snapshot stays in the source.
