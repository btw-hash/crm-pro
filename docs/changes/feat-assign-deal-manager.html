Head of sales reassigns a deal to a manager

#210 · "↪ Reassign" on the kanban board + notification to the recipient

What changed

  • The head of sales sees a ↪ Reassign button on every kanban card — it opens a mini popover with a manager picker.
  • On reassignment — a notification to the new owner: "The head of sales reassigned a deal to you…" (in the notifications feed, the bell in the header).
  • RBAC: the button is shown only to the head role. The manager and technologist don't see it. The server action duplicates the role check (a direct POST bypassing the UI doesn't get around it).
  • No-op if the owner is already the same — a duplicate notification isn't created.
  • New use case assignDealManager covered by 5 tests (TDD).
