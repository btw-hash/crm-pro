AI spend — now broken down by employee

Which managers spend how many tokens and dollars on AI — over a period

What was built (#405, an extension of #401)

  • Every AI call is now tied to the employee who initiated it (via the session). The "AI spend" screen now has a "By employee" breakdown: calls, tokens, and cost per manager over the period.
  • Data-privacy compliance: only a surrogate id for the employee is written to the log (not a name/email); a readable name is substituted on screen from the reference table. Calls outside a session appear as "System / no session".
  • Works with both AI providers — doesn't depend on prompt caching.

Before → after

AI spend Before After
Breakdowns Only "by feature" (what we spend on) "By feature" + "By employee" (who's spending)
Attribution Anonymous department-wide spend Spend tied to a manager (surrogate id → name on screen)

How to verify

  1. Log in as head of sales (demo login "Alan").
  2. Open "AI spend" in the menu.
  3. On a stand with live AI (AI_MODE=live), ask the assistant a few questions from different users — a "By employee" table appears below the "By feature" table, with calls, tokens, and cost for each person.
  4. In stub mode there's no data (the model isn't called) — both tables are empty, showing an honest empty state.

NB: in-memory mode shows a breakdown of the most recent calls (a ring buffer); full history for a period comes from Postgres.
