#307 · Analytics: "by manager/product" breakdown + enriched export

A follow-up on top of the merged #348 (which added the chart period and tooltips). We're only adding the unique value: the "Breakdown" switcher (?view=) and export of the whole analytics view under the selected breakdown. The period and tooltips from #348 are untouched.

Context

Issue #307 ("bring analytics buttons/charts to life") was closed by the parallel PR #348: the dead period button → a working PeriodSelect (?period= 4/6/12 mo/all), charts got native title tooltips, a basic export (by manager, from #313/#343). This PR does not duplicate or revert #348 — it adds on top what's missing there.

What's added on top of #348

  • "Breakdown: …" — a dropdown switcher for the revenue breakdown (by manager / by product). Changes ?view= in the URL; the server page re-reads the param (SSR) and rearranges the breakdown cards: the selected breakdown becomes the "large" card (avatars/shares), the other one becomes a complementary bar. Labeled "Breakdown:" so it isn't confused with their "View:" (period).
  • Enriched "Export" — reuses the shared ExportButton (#313/#343, the CSV format/download isn't duplicated): only the headers/ rows props were replaced. It now exports the breakdown rows (revenue + share) under the selected ?view= plus the month-by-month trend for the visible window ?period=. The filename reflects the breakdown and period.

Their PeriodSelect, ?period=, and chart title tooltips are left as-is — my period switcher and popup tooltips from the PR #347 draft were removed to avoid duplicates.

Repro steps

  1. Open /analytics as Head of sales.
  2. In the header — a "Breakdown: by manager ▾" button. Click → pick "by product" → the URL gets ?view=products, the breakdown cards swap places (products becomes the large one).
  3. Click "Export" → downloads analytics-products-4.csv (4 — the current period from #348): product revenue rows + the month-by-month trend. Opens in Excel (BOM + ;).
  4. Change the period to "View: Last 12 months" (the #348 component) → "Export" again → analytics-products-12.csv with 12 months of trend data.
  5. The period/tooltips from #348 keep working as before (we didn't touch them).
  6. Verified with unit tests (we didn't run a browser in the worktree): breakdown selection by param, CSV assembly from data, pushing/clearing ?view=. npm run verify + build — green.
